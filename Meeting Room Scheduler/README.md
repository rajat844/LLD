# Meeting Room Scheduler

## Requirements

1. A user can book the meeting rooms availabilty.
2. A user can also book 2 types of meetings
    - One Time Meeting
    - Reccuring Meeting
3. User can cancel the meeting. For recurring meeting user can cancel indivisual meeting also can cancel whole meeting.
4. There would be multiple sizes of meetings room, it will be assigned automatically based on count of attendes.

## Core Entities

1. Meeting
2. User
3. Meeting Room
4. Meeting Room Scheduler
5. Meeting Room Calender
