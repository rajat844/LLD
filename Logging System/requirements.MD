# Logging System

## Functional Requirements

1. A client application can create a log entry by supplying a log level and message.
2. The logger can have multiple handlers. Eg : FATAL, ERROR, WARN, DEBUG, INFO.
3. The client application can output logs in a txt file or to the console.
4. The client application can format logs as an JSON object or as a text line.

## Entites

1. Logger
2. Log Handler
3. LogType
4. Log Message
5. Format Strategy
6. Output Strategy
